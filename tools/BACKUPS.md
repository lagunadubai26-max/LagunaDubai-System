# النسخ الاحتياطية وتجربة الاستعادة

## تنزيل النسخة

من حساب المدير افتح **الإعدادات → النسخ الاحتياطية**، ثم «تنزيل نسخة JSON».
الملف يحتوي جميع مجموعات النظام الـ27، مع معرف المستند الفعلي وقيم Firestore
(المقاسات، الفواتير، الشيفتات، الإغلاقات، الإعدادات، الحسابات، المخزون وغيرها).
تُقرأ البيانات من السيرفر على صفحات؛ فشل أي قراءة يمنع إخراج ملف جزئي.

احتفظ بالملف خارج الجهاز أيضًا. التذكير أسبوعي داخل لوحة التحكم، ويعتمد على
آخر طلب تنزيل في هذا المتصفح؛ لا يعمل والموقع مغلق، ولا يثبت أن الملف بقي على القرص.
يتضمن الملف الحسابات والإعدادات، لذلك يُحفظ في مكان خاص.

النسخة قراءات متتابعة وليست لقطة ذرية لقاعدة البيانات. للحصول على نسخة متسقة
خُذها بعد إغلاق الشيفت وفي وقت لا يجري فيه تعديل البيانات من الأجهزة الأخرى.
لا تشمل النسخة ملفات Firebase Storage أو كود الموقع أو قواعد Firestore أو حسابات
Firebase Authentication؛ صور المنتجات المخزنة داخل المستندات تشملها النسخة.

## فحص الملف

اختيار ملف من «فحص نسخة محفوظة» يفحص البنية والمجموعات والمعرفات وبصمة SHA-256.
هذا يكشف التلف أو التعديل، وليس توقيعًا يثبت هوية مصدر الملف.

من الطرفية باستخدام Node.js 20 أو أحدث:

```bash
node tools/restore-backup.cjs /path/to/laguna-backup.json
```

الفحص وحده لا يكتب أي بيانات.

## تجربة استعادة فعلية في قاعدة اختبار محلية

ثبت Firebase CLI وJava المتوافق مع نسختها، ثم شغّل محاكي Firestore:

```bash
npx firebase-tools emulators:start --only firestore --project demo-laguna-restore --config tools/backup-emulator.json
```

في طرفية ثانية، اختَر اسم مشروع اختبار جديدًا يبدأ بـ`demo-`:

```bash
node tools/restore-backup.cjs /path/to/laguna-backup.json --restore --emulator http://127.0.0.1:8080 --project demo-laguna-test-1
```

الأداة ترفض قاعدة اختبار غير فارغة، وتكتب كل مستند ثم تقرأه وتقارن محتواه، وتعرض
عدد المستندات المستعادة. تُعاد توجيه مراجع مستندات المشروع إلى مشروع الاختبار.
الأداة تقبل محاكيًا محليًا فقط؛ ليست أداة استعادة إلى قاعدة الإنتاج.
إذا انقطعت التجربة، اختَر مشروع `demo-` جديدًا عند إعادة التشغيل.

استعادة الإنتاج تحتاج إجراءً مستقلًا ينسق قواعد Firestore وحسابات تسجيل الدخول
وربط الأدوار بمعرفات Firebase Authentication. نجاح استعادة المستندات وحده لا يعيد
حسابات تسجيل الدخول أو الطابعات الخارجية.
