# دليل كامل من الصفر — توصيل الطابعات وتشغيل النظام

## أول حاجة: محتاج إيه؟

1. **جهاز كاشير** — عليه وندوز جديد فاضي
2. **طابعتين XP-Q808K**
   - الأولى: طابعة الكاشير (هتوصلها USB + فيها الدرج)
   - التانية: طابعة المطبخ (هتوصلها كابل شبكة)
3. **درج الفلوس (Cash Drawer)** — فيه كابل بـ RJ11/RJ12 (زي كابل التليفون)
4. **راوتر/شبكة** — عشان تصل طابعة المطبخ

---

## الخطوة 1: وصّل طابعة الكاشير (USB) + الدرج

### 1.1 وصّل USB
- خد كابل USB
- وصله في طابعة XP-Q808K الأولى
- وصله في جهاز الكاشير
- الطابعة هتظهر في Device Manager لكن مش هتشتغل دلوقتي

### 1.2 وصّل الدرج
- دور في الطابعة على بورت صغير مكتوب عليه **Drawer** أو **Cash** أو علامته ↓↑
- خد كابل الدرج (طرفه RJ11/RJ12 زي كابل التليفون)
- وصله في البورت ده
- **الدرج مش بيتوصل بالكمبيوتر** — هو مربوط بالطابعة

### 1.3 وصّل كهربا الطابعة
- وصّل سلك الكهربا في الطابعة
- وشغلها
- الطابعة هتتحرك شوية وتطبع خط — يبقى شغالة

---

## الخطوة 2: وصّل طابعة المطبخ بالشبكة

### 2.1 وصّل كابل الشبكة
- خد كابل Ethernet (Rj45 زي بتاع النت)
- وصله في طابعة XP-Q808K التانية
- وصله في الراوتر
- وصّل كهربا الطابعة وشغّلها

### 2.2 ظبط IP ثابت للطابعة

الطابعة محتاجة عنوان ثابت عشان مايتغيرش كل ما الراوتر يعيد تشغيل.

**الطريقة: من الراوتر (الأسهل)**

1. على جهاز الكاشير، افتح المتصفح
2. اكتب في شريط العنوان: `192.168.1.1` (أو `192.168.0.1` — دور على sticker في الراوتر)
3. هتدخل صفحة الراوتر — عاوز username/password (غالباً admin/admin أو مكتوب على الراوتر)
4. دور على حاجة اسمها **DHCP Reservation** أو **Address Reservation**
5. هتطلب منك **MAC Address** بتاع الطابعة
   - على استيكر في الطابعة نفسها
   - أو من Device Manager في الويندوز
6. اكتب MAC Address
7. وحط IP ثابت مثلًا: `192.168.1.50`
8. احفظ

**طريقة تانية: جرب IP**

1. افتح CMD على جهاز الكاشير: اضغط Win + R, اكتب `cmd`, Enter
2. اكتب `ipconfig` وشوف IPv4 بتاعك (مثال: 192.168.1.10)
3. جرب تكتب في CMD:
```
ping 192.168.1.50
```
4. لو جابت رد — يبقى ده IP الطابعة (حد مسبقاً ضبطها كده)
5. لو مجابتش رد — جرب `ping 192.168.1.100`، `ping 192.168.1.200`، إلخ
6. أول IP يرد عليه — ده الطابعة

**طريقة تالتة: من برنامج Xprinter**
- خش على موقع Xprinter وحمل "Configuration Tool" أو استخدم القرص اللي مع الطابعة
- شغّله، هيدور على الطابعات في الشبكة ويوريك IP كل واحدة
- تقدر تغير الـ IP من نفس البرنامج

### 2.3 اتأكد إن الطابعة على الشبكة
في CMD:
```
ping 192.168.1.50 -t
```
اضغط Ctrl+C عشان توقف. لو شفت "Reply from..." يبقى الطابعة وصلت.

## الخطوة 6: ثبت Zadig (درايفر USB)

الدرايفر العادي بتاع وندوز مش بيخلّي Node.js يكلم الطابعة. محتاج درايفر خاص.

1. افتح `https://zadig.akeo.ie/`
2. دوس على **Zadig 2.9** (ينزل ملف exe)
3. افتح الملف (مش محتاج تثبيت)
4. في Zadig:
   - من القائمة اللي فوق، اختار **Options** > **List All Devices**
   - من القائمة المنسدلة الكبيرة، دور على **"XP-Q808K"** أو **"USB Printer"** أو **"Xprinter"**
5. ما لقتهاش؟
   - اتأكد إن الطابعة متوصلة وشغالة (فيها نور)
   - جرب كابل USB تاني
   - جرب منفذ USB تاني
6. بعد ما تختار الطابعة:
   - من القائمة اللي تحت (Driver)، اختار **WinUSB**
   - دوس **Replace Driver** (أو **Install Driver**)
   - استنى — هتظهر **"Success"**
7. خلاص — الطابعة دلوقتي تقدر تشتغل مع Node.js

**ملاحظة مهمة:** بعد كده الطابعة مش هتطبع من وورد ولا إكسل — ده طبيعي. الطابعة بتشتغل مع الـ Agent بس.

## الخطوة 7: عدّل ملف config.js

1. افتح مجلد `print-agent` من سطح المكتب
2. دوس كليك يمين على الملف **config.js**
3. اختار **Open with Notepad**
4. هتلاقي الكلام ده:

```js
module.exports = {
  serverPort: 4321,

  cashierPrinter: {
    type: "usb",
    vendorId: null,
    productId: null,
  },

  kitchenPrinter: {
    type: "network",
    ip: "192.168.1.50",
    port: 9100,
  },

  drawerKick: {
    pin: 0,
    onTime: 25,
    offTime: 25,
  },
};
```

### 7.1 غير IP طابعة المطبخ
- دور على السطر: `ip: "192.168.1.50"`
- غير `192.168.1.50` لـ IP طابعة المطبخ بتاعتك (اللي عرفته في الخطوة 2)
- مثلًا: `ip: "192.168.1.100"`

### 7.2 لو عايز تحدد USB بالـ VID/PID (اختياري)
- افتح Zadig تاني
- جمب اسم الطابعة مكتوب حاجة زي `VID 1FC9 PID 2016`
- غير config.js لـ:
```js
cashierPrinter: {
  type: "usb",
  vendorId: 0x1FC9,
  productId: 0x2016,
},
```
- الأرقام دي تختلف من طابعة للتانية

### 7.3 احفظ الملف
- File > Save
- قفل Notepad

## الخطوة 8: شغّل الـ Agent

1. ارجع للـ Terminal (الشاشة السودة) في مجلد print-agent
2. اكتب:
```

```
3. المفروض تشوف الكلام ده:
```
Print Agent شغال على http://localhost:4321
رابط الصحة: http://localhost:4321/health
```
4. **النافذة دي متقفلهاش** — طول ما هي مفتوحة، الـ Agent شغال

### اختبار سريع
1. افتح متصفح على جهاز الكاشير
2. اكتب: `http://localhost:4321/health`
3. المفروض تشوف:
```json
{ "ok": true, "message": "Print Agent شغال تمام" }
```

## الخطوة 9: اختبر الطباعة

### جرب تطبع فاتورة اختبار من PowerShell

1. افتح PowerShell (Win + R, اكتب `powershell`, Enter)
2. انسخ الكود ده والصقه (كليك يمين في PowerShell):
```powershell
$body = @{
    storeName = "كافيه لاجونا"
    id = "TEST-001"
    customer = "اختبار"
    items = @(
        @{ name = "قهوة تركي"; qty = 2; price = 30 }
        @{ name = "كرواسون"; qty = 1; price = 40 }
    )
    total = 100
    paid = 100
    paymentMethod = "كاش"
}
Invoke-RestMethod -Uri "http://localhost:4321/print-invoice" -Method Post -ContentType "application/json" -Body ($body | ConvertTo-Json)
```

لو اطبع من طابعة الكاشير + طابعة المطبخ + الدرج اتفتح — يبقى كل حاجة شغالة.

لو ما اطبعتش:
- طابعة الكاشير: راجع Zadig (WinUSB)
- طابعة المطبخ: راجع IP (اعمل ping)
- الدرج: جرب تغير `pin: 0` لـ `pin: 1` في config.js

## الخطوة 11: خلّي الـ Agent يشتغل تلقائي (مش مهم)

عشان ما تضطرش تفتح CMD كل يوم و تكتب `npm start`:

### الطريقة: PM2

1. افتح CMD في مجلد print-agent
2. اكتب:
```
npm install -g pm2
```
3. اكتب:
```
pm2 start server.js --name print-agent
```
4. اكتب:
```
pm2 save
```
5. اكتب:
```
pm2 startup
```
6. هيديك أمر طويل زي:

   ```
   pm2 startup system-info -u [اسم] --hp [المسار]
   ```
   
   انسخ الأمر ده وشغّله

7. خلاص — بعد كل ريستارت للجهاز، الـ Agent يشتغل تلقائي

### طريقة تانية: Startup Folder

1. افتح Notepad
2. اكتب:
```batch
@echo off
cd /d C:\Users\[اسمك]\Desktop\print-agent
node server.js
```
3. File > Save As
4. اسم الملف: `start-agent.bat`
5. المكان: سطح المكتب
6. دوس Win + R, اكتب `shell:startup`, Enter
7. انسخ اختصار الملف `start-agent.bat` من سطح المكتب للمجلد اللي فتح

## مشاكل وخلها

### الطابعة مش بتطبع
- **الـ Agent شغال؟** — شوف نافذة CMD لسه مفتوحة
- **Zadig متنزل؟** — افتح Zadig وشوف لو WinUSB موجود
- **جرب كابل USB تاني** — بعض الكابلات بتاع الشحن مش بتاع بيانات

### طابعة المطبخ مش واصلة
- اعمل ping للـ IP:
  ```
  ping 192.168.1.50
  ```
  لو مجابش رد، IP غلط
- اتأكد إن كابل الشبكة في الراوتر (فيه نور في مكان الكابل)

### الدرج مش بيفتح
- اتأكد إن كابل الدرج في بورت Drawer في الطابعة
- جرب تغير `pin: 0` لـ `pin: 1` في config.js
- جرب تغير الـ onTime لـ 50

### لما أفتح الموقع مش باطبع (CORS error)
- استخدم HTTP مش HTTPS
- افتح المتصفح واكتب: `chrome://flags/#block-insecure-private-network-requests`
- عطّلها (Disabled)
- أعد تشغيل المتصفح

### عاوز أرجع الطابعة تشتغل عادي من وورد
- افتح Device Manager
- دور على الطابعة تحت "Universal Serial Bus devices"
- كليك يمين > Properties > Driver > Update Driver
- Browse my computer > Let me pick
- اختار الدرايفر الأصلي
