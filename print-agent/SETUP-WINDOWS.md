1. تجهيز جهاز الكاشير

## 1. تجهيز جهاز الكاشير

جهاز الكاشير فاضي (وندوز جديد). محتاج تعمل الآتي:

- اشبك الجهاز على **نفس الشبكة** اللي راكب عليها طابعة المطبخ (نفس الراوتر)
- يفضل توصيله بـ **كابل شبكة (Ethernet)** مش WiFi — عشان الطابعة المطبخ تفضل شغالة لو WiFi فصل
- خلي الجهاز ياخد IP تلقائي من الراوتر (DHCP) — ده عادي، إحنا مش محتاجين IP ثابت للجهاز نفسه

## 2. توصيل طابعة الكاشير (USB) + الدرج

الطابعة الأولانية (XP-Q808K) هتكون طابعة الكاشير.

### 2.1 توصيل كابل USB
- وصل كابل USB من الطابعة لجهاز الكاشير
- الطابعة هتظهر تلقائي في الـ Device Manager بس مش هتشتغل دلوقتي — إحنا هنركب درايفر خاص بعدين

### 2.2 توصيل الدرج (Cash Drawer)
- الدرج فيه كابل بيخلص بـ RJ11/RJ12 (زي كابل التليفون)
- دور في الطابعة على بورت مكتوب عليه **"Drawer"** أو **"Cash"** أو بجانبه علامة درج ↓↑
- ووصّل كابل الدرج في البورت ده

**ملاحظة مهمة:** الدرج مش بيتوصل بـ USB، وكابله مش راكب في جهاز الكمبيوتر. الدرج مربوط بالطابعة نفسها. الطابعة بتفتح الدرج لما تستقبل أمر ESC/POS معين.

### 2.3 تشغيل الطابعة
- واصل سلك الكهربا بتاع الطابعة
- شغّلها
- الطابعة هتخلص initialization (تتحرك شوية وتطبع خط)
- خلاص — طابعة الكاشير جاهزة (الدرج مربوط فيها)

## 3. توصيل طابعة المطبخ (Network / LAN)

الطابعة التانية (XP-Q808K) هتكون في المطبخ، مش هتوصلها USB. هتوصلها بالشبكة.

### 3.1 توصيل كابل الشبكة
- الطابعة فيها منفذ **RJ45 Ethernet** (نفس بتاع اللاب توب)
- واصل كابل شبكة من الراوتر للطابعة
- واصل سلك الكهربا وشغّلها

### 3.2 ضبط IP ثابت للطابعة

الطابعة غالباً هتاخد IP تلقائي بس ممكن يتغير بعد كل ريستارت الراوتر. عشان كده لازم تظبطها Static IP.

#### طريقة 1 (الأسهل): من الراوتر
خش على إعدادات الراوتر:
- دور على **DHCP Reservation** أو **Address Reservation**
- اعرف الـ MAC Address بتاع الطابعة (مكتوب على استيكر أسفل الطابعة أو من Device Manager)
- احجز IP ثابت مثلًا **192.168.1.50**

#### طريقة 2: من شاشة الطابعة
لو XP-Q808K فيها شاشة:
- ادخل **Menu > Network > IP Mode > Static**
- ظبط:
  - IP Address: `192.168.1.50`
  - Subnet Mask: `255.255.255.0`
  - Gateway: `192.168.1.1` (IP الراوتر بتاعك)

#### طريقة 3: من موقع الطابعة
لو مش عارف IP الطابعة:
1. من جهاز الكاشير، دور على البرنامج الرسمي من Xprinter (على القرص اللي مع الطابعة أو من موقع الشركة)
2. استخدم أداة زي **"Xprinter Configuration Tool"**
3. بتوريك IP الطابعة الحالي وتقدر تغيره

**طريقة بديلة تجيب IP الطابعة:**
- من جهاز الكاشير، افتح CMD واكتب:
```
ipconfig
```
- هتشوف الشبكة بتاعتك (مثال: 192.168.1.x)
- جرب تطبع ping للعنواين المتوقعة (زي .50, .100, .200)
```
ping 192.168.1.50
```
لما تلاقي رد، يبقا ده IP الطابعة.

### 3.3 اختبار أن الطابعة على الشبكة
```
ping 192.168.1.50 -t
```
لما تضغط Ctrl+C، لو جابت ردود يبقى تمام.

## 4. تثبيت Node.js

الـ Print Agent محتاج Node.js عشان يشتغل.

1. افتح الموقع: https://nodejs.org
2. نزّل **LTS version** (أحدث إصدار طويل الدعم — مثلًا 20.x أو 22.x)
3. شغّل الـ installer
4. في خطوة التثبيت، **كل حاجة زي ماهي — Next Next Next**
5. علامة صح عند "Automatically install necessary tools" لو ظهرت اختارها
6. خلص التثبيت

### تأكد إنه اتثبت صح
افتح CMD واكتب:
```
node --version
npm --version
```
لو ظهر أرقام زي v20.x.x و 10.x.x يبقى تمام.

## 5. تجهيز مجلد Print Agent

الملفات دي موجودة في مجلد `print-agent/` في المشروع الأصلي.

### 5.1 نزل المشروع
نزّل مجلد `print-agent/` على جهاز الكاشير:
- انسخ المجلد كامل من المشروع إلى جهاز الكاشير (فالاشة USB أو تيلي جرام أو البريد)
- حطه في مكان مثلًا: `C:\laguna-print-agent\`

### 5.2 ثبت الحزم
افتح CMD في مجلد `C:\laguna-print-agent\` واكتب:
```
npm install
```
ده بينزل الـ dependencies (express, cors, escpos, إلخ). المفروض يطلع مجلد `node_modules` جديد.

## 6. تثبيت Zadig (درايفر USB للطابعة)

وده **أهم خطوة وأكثرها غرابة** لو أول مرة تعملها:

Node.js مش بيقدر يكلم الطابعة عبر USB بالدرايفر العادي بتاع Windows. محتاج درايفر خاص اسمه **WinUSB**.

### 6.1 نزّل Zadig
https://zadig.akeo.ie/
- الضغط على "Zadig 2.9" (أو آخر إصدار)
- هينزل ملف `.exe` واحد صغير — شغّله (مش محتاج تثبيت)

### 6.2 عرف طابعة XP-Q808K
لما تفتح Zadig:
1. من القائمة اللي فوق (Options) اختار **"List All Devices"** (عشان يظهر كل الأجهزة مش الطابعات بس)
2. من القائمة المنسدلة الكبيرة، دور على **"XP-Q808K"** أو **"USB Printer"** أو **"Xprinter"**
3. لو مش ظاهر:
   - تأكد إن الطابعة متوصلة وشغالة
   - غير الكابل USB لو لزم (بعض الكابلات شحن بس مش بيانات)
   - جرب منفذ USB تاني

### 6.3 ركّب الدرايفر
1. بعد ما تختار الطابعة، من القائمة اللي تحت (Driver) اختار **WinUSB** (لو مش موجود اختار **libusbK**)
2. دوس **"Install Driver"** أو **"Replace Driver"**
3. استنى شوية — هتظهر رسالة نجاح

**مهم جداً:** بعد كده الطابعة مش هتشتغل مع الـ Windows Printer Driver العادي (يعني مش هتظهر في الـ Control Panel ولا تطبع من Notepad أو Excel). ده طبيعي — الطابعة دلوقتي بتشتغل مع الـ Agent بس.

لو عايز ترجعها لحالتها الطبيعية:
- افتح **Device Manager**
- دور على الطابعة تحت "Universal Serial Bus devices"
- كليك يمين > Properties > Driver > Update Driver > Browse my computer > Let me pick > اختار الدرايفر الأصلي

## 7. ضبط إعدادات الطابعات في config.js

افتح `C:\laguna-print-agent\config.js` بـ Notepad (أو VS Code لو عندك).

### 7.1 طابعة الكاشير (USB)

```js
cashierPrinter: {
  type: "usb",
  vendorId: null,
  productId: null,
},
```

**خليهم `null`** — الـ Agent هيدور على أول طابعة USB لاقاها. ده أسهل حاجة وغالباً شغال.

لو عايز تحدد بالظبط (مثلاً لو في أكتر من طابعة USB):
- افتح **Zadig** تاني
- الطابعة الظاهرة هتلاقي جنبها أرقام زي `VID 1FC9` و `PID 2016`
- ظبطها كده:
```js
cashierPrinter: {
  type: "usb",
  vendorId: 0x1FC9,
  productId: 0x2016,
},
```

### 7.2 طابعة المطبخ (Network)

غير IP طابعة المطبخ الفعلي:

```js
kitchenPrinter: {
  type: "network",
  ip: "192.168.1.50",     // ← حط IP طابعة المطبخ هنا
  port: 9100,
},
```

### 7.3 الدرج (Drawer)

```js
drawerKick: {
  pin: 0,
  onTime: 25,
  offTime: 25,
},
```

ده **إعداد قياسي** لـ XP-Q808K. لو الدرج ما فتحش بعدين، جرب:
- `pin: 1`
- `{ pin: 0, onTime: 50, offTime: 50 }`

### 7.4 السيرفر

```js
serverPort: 4321,
```

سيبه 4321 عادي.

### ملف config.js كامل بعد التعديل:

```js
module.exports = {
  serverPort: 4321,

  cashierPrinter: {
    type: "usb",
    vendorId: null,
    productId: null,
  },

  kitchenPrinter: {
    type: "network",
    ip: "192.168.1.50",
    port: 9100,
  },

  drawerKick: {
    pin: 0,
    onTime: 25,
    offTime: 25,
  },
};
```

## 8. تشغيل الـ Agent

افتح CMD في مجلد `C:\laguna-print-agent\` واكتب:
```
npm start
```

المفروض تشوف:
```
Print Agent شغال على http://localhost:4321
رابط الصحة: http://localhost:4321/health
```

**متقفلش نافذة CMD دي** — طول ما هي مفتوحة، الـ Agent شغال.

### اختبار سريع
افتح متصفح على جهاز الكاشير ودوس على الرابط ده:
```
http://localhost:4321/health
```
لما يظهر `{ "ok": true, "message": "Print Agent شغال تمام" }` يبقى تمام.

### تشغيل الطابعتين
جرب ترسل فاتورة اختبار للـ Agent (من CMD تاني):
```bash
curl -X POST http://localhost:4321/print-invoice ^
  -H "Content-Type: application/json" ^
  -d "{\"storeName\":\"كافيه لاجونا\",\"id\":\"TEST-001\",\"customer\":\"اختبار\",\"items\":[{\"name\":\"قهوة تركي\",\"qty\":2,\"price\":30},{\"name\":\"كرواسون\",\"qty\":1,\"price\":40}],\"total\":100,\"paid\":100,\"paymentMethod\":\"كاش\"}"
```

لو ما عندكش curl:
```
npm install -g curl
```
أو استخدم Postman / ThunderClient، أو اكتب الأمر ده في PowerShell:
```powershell
$body = @{
    storeName = "كافيه لاجونا"
    id = "TEST-001"
    customer = "اختبار"
    items = @(
        @{ name = "قهوة تركي"; qty = 2; price = 30 }
        @{ name = "كرواسون"; qty = 1; price = 40 }
    )
    total = 100
    paid = 100
    paymentMethod = "كاش"
}
Invoke-RestMethod -Uri "http://localhost:4321/print-invoice" -Method Post -ContentType "application/json" -Body ($body | ConvertTo-Json)
```

لو اطبع الفاتورة (الكاشير) + أمر المطبخ + فتح الدرج كلهم في نفس الوقت — يبقى كل حاجة شغالة.

## 9. ربط الموقع بالـ Agent

دلوقتي الموقع نفسه محتاج يعرف عنوان الـ Agent عشان يبعتله الفواتير.

من **أي جهاز عليه الموقع** (جهاز الكاشير نفسه أو حتى موبايل على نفس الشبكة):

1. افتح صفحة **الإعدادات** (settings.html)
2. تحت "إعدادات الطباعة"
3. فعّل **"استخدام Print Agent"**
4. في حقل **"رابط Print Agent"** اكتب: `http://192.168.1.100:4321` (استبدل بـ IP جهاز الكاشير الفعلي)

**طريقة معرفة IP جهاز الكاشير:**
على جهاز الكاشير، افتح CMD واكتب:
```
ipconfig
```
دور على IPv4 Address بتاع الـ Ethernet adapter — غالباً حاجة زي `192.168.1.XXX`

### لو الموقع والـ Agent على نفس الجهاز
جرب الأول بـ:
```
http://localhost:4321
```

بس للشغل الفعلي استخدم IP الجهاز عشان الموبايلات والأجهزة التانية توصله.

5. اضغط "حفظ الإعدادات"

### من الآخر — خلاص كده
أفتح صفحة المنيو (menu.html)، أطلب أي حاجة، وادفع. هتلاقي:
- 🖨️ **طابعة الكاشير (USB)** طبعت الفاتورة
- 🖨️ **طابعة المطبخ (Network)** طبعت أمر المطبخ
- 💵 **الدرج** اتفتح

كله في نفس اللحظة.

## 10. تشغيل الـ Agent تلقائي مع بداية تشغيل الجهاز

عشان متفتحش CMD كل يوم:

### الطريقة 1: PM2 (أفضل حل)
في CMD:
```
npm install -g pm2
pm2 start server.js --name print-agent
pm2 save
pm2 startup
```
الـ startup هيديك أمر CMD محتاج تشغله عشان PM2 يشتغل مع بداية الويندوز.

### الطريقة 2: اختصار في Startup
1. اعمل ملف `.bat` جديد في `C:\laguna-print-agent\start-agent.bat`:
```batch
@echo off
cd /d C:\laguna-print-agent
node server.js
```
2. دوس Win + R, اكتب `shell:startup`
3. حط اختصار للملف `.bat` في المجلد اللي فتح

## مشاكل وحلول

### الطابعة مش بتطبع
- تأكد من درايفر Zadig (WinUSB)
- جرب كابل USB تاني
- جرب منفذ USB تاني في الجهاز
- شوف رسالة الخطأ في CMD اللي شغال عليه الـ Agent

### الدرج مش بيفتح
- تأكد إن كابل الدرج في بورت Drawer بالطابعة مش في حتة تانية
- جرب تغير `pin` في config.js لـ 1
- اختبر بأمر مباشر: `printer.cashdraw(0)`

### طابعة المطبخ مش بتطبع
- اعمل `ping 192.168.1.50` — لو مجابش رد يبقى IP غلط
- تأكد إن كابل الشبعة راكب في الراوتر مش في الكمبيوتر
- جرب تطبع ملف test page من موقع Web Config بتاع الطابعة (جرب `http://192.168.1.50` في المتصفح لو الطابعة فيها واجهة ويب)
- البرنامج الافتراضي بيشتغل على **port 9100** — ده المعيار لكل طابعات ESC/POS

### CORS error
مفروض ميحصلش لأن السيرفر فيه `app.use(cors())`. لو حصل، تأكد إنك بتستخدم رابط HTTP مش HTTPS (لأن السيرفر HTTP, وGitHub Pages HTTPS — بعض المتصفحات بتمنع mixed content). الحل:
- خش على `chrome://flags/#block-insecure-private-network-requests` وعطلها
- أو استخدم HTTPS للـ Agent (بـ mkcert) — ده موضوع متقدم

### الـ Agent مش شغال بعد ريستارت
- لو استخدمت PM2, اعمل `pm2 list` وشوف لو الـ task شغال
- لو استخدمت Startup, تأكد إن الملف في المكان الصح
